# PUBG Mobile Research & API Evaluation

Reverse engineering research and investigation into PUBG Mobile player verification, profile, and inventory/collection data flows.

## Structure

- `research/pubg/`: Master research logs, state machine, and experiment documentation.
  - `uid-resolvers/`: Analysis of web top-up resolvers (VNG web shop, Midasbuy, GoPay Games / `triyatna/php-valid-game`).
  - `experiments/`: Experiment setups and execution plans.
- `research/pubg-uid-api/`: GoPay direct HTTP test suite and benchmarks.
- `research/pubg-vng-uid/`: VNG web shop automated flow and CDP network captures.
