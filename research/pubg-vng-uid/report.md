- whether UID is sent directly:
  In `POST /interface/getCharac`, UID is encrypted on the client side using Midasbuy web SDK (`encrypt_msg` + `ctoken`). In subsequent internal catalog call `POST /frontend/api/midasbuy/v1/shelves/query`, UID is sent directly in cleartext as `role_id: "5421835339"`.
- whether VNG performs a backend request:
  Yes. The website communicates with backend `pay.pubgm.zing.vn` running Nginx and `VNG-GPT-SEA` proxying to Midasbuy SaaS backend.
- whether nickname is returned by that request:
  Yes. Returned directly in HTTP 200 response body under `info.charac_name` as URL-encoded UTF-8 bytes (`Duwn%E9%BB%8E%E6%9D%A8`), which decodes exactly to `Duwn黎杨`.

  Yes. A 17-digit Tencent internal OpenID `openid: "25877658659587368"` was uncovered in the response object.
- whether server/region information appears:
  Yes. `zoneid: "1"` is returned in the response object.
- whether authentication/session is required:
  No user login or authentication is required. The lookup functions completely anonymously without credentials. Rate limiting is enforced via HTTP header (`x-ratelimit-limit: 30`, `x-ratelimit-remaining: 29`).

## 13. Evidence vs inference

### Directly observed
1. URL `https://shop.vnggames.com/vn` delegates PUBG Mobile VN top-up to `https://pay.zing.vn/pubgm`.
2. `https://pay.zing.vn/pubgm` embeds Midasbuy SaaS frontend at `https://pay.pubgm.zing.vn/pubgmvn/vn/buy/pubgmvn` and `https://pay.pubgm.zing.vn/common-sdk?id=playerid_enter`.
3. Submitting UID `5421835339` immediately fires `POST https://pay.pubgm.zing.vn/interface/getCharac`.
4. Response body of `POST /interface/getCharac` contains:
   `{"ret":0,"info":{"zoneid":"1","openid":"25877658659587368","charac_name":"Duwn%E9%BB%8E%E6%9D%A8","active_country":"","register_country":"","is_ban":false}}`.
5. Decoding `Duwn%E9%BB%8E%E6%9D%A8` gives `Duwn黎杨`.
6. UI displays `Duwn黎杨 (5421835339)` on the upper header.
7. Subsequent request `POST https://pay.pubgm.zing.vn/frontend/api/midasbuy/v1/shelves/query` explicitly contains `role_id: "5421835339"`, `game_openid: "25877658659587368"`, and `character_name: "Duwn黎杨"`.
8. Rate limit response headers indicate `x-ratelimit-limit: 30`.

### Inference
1. The field `openid: "25877658659587368"` is Tencent's global account OpenID for the player profile in PUBG Mobile backend services.
2. The payload in `POST /interface/getCharac` uses Midasbuy client-side encryption (`encrypt_msg` + `ctoken`), requiring encryption emulation for standalone direct API calls.
